# GDC Essential Skills

A graphics display calculator (GDC) helps you **explore and check** a pattern. It does not replace the algebra that explains why the pattern works. Know which of your exam papers allow a GDC and which do not.

## Three habits worth practising

| Task | Useful approach | What to record |
| --- | --- | --- |
| List sequence terms | Define the rule and view a table | First terms and their indices |
| Evaluate a sum | Use a sum or sequence command | Limits, expression, and result |
| Check a graph | Set a sensible window | Intercepts or behaviour relevant to the question |

For a geometric sequence with first term \(3\) and ratio \(2\), enter a rule such as:

```text
u(n) = 3 × 2^(n - 1)
n = 1, 2, 3, ...
```

The table should begin \(3,6,12,24\). That is a useful check on the indexing: if the first output is \(6\), you may have typed \(3(2^n)\) instead.

## Use technology carefully

A very large computed value is **evidence**, not proof. For example, evaluating \(7^n-1\) for many integers suggests divisibility by \(6\), but only a general argument establishes it for every positive integer.

**Try it:** Use your GDC to list the first eight terms of \(u_n=5+3(n-1)\), then calculate the eighth term by hand. Do both methods agree?

> **Exam lens:** Write down the rule you entered. A screen result without a mathematical setup can be hard to credit.
