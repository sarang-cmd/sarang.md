# Transformations of functions

> **SL 2.11 · AA SL foundation (also studied at HL)** · Original Sarang.md course lesson, not an IB publication.

## Understand the idea

A transformation changes a graph without recalculating every point. Changes inside a function act on inputs and often reverse the intuitive direction; changes outside act on outputs. The order matters when stretches and translations are combined.

## Formula, meaning and conditions

If $y=f(x)$, then $f(x-h)+k$ shifts right $h$ and up $k$. Multiplying outside by $a$ scales vertical distances by $|a|$ and reflects in the $x$-axis when $a<0$. For $f(bx)$, horizontal distances scale by $1/|b|$.

## Worked example

Start with $f(x)=x^2$. For $g(x)=-2(x-3)^2+1$, shift right $3$, stretch vertically by $2$, reflect in the $x$-axis, then shift up $1$. The vertex moves from $(0,0)$ to $(3,1)$ and becomes a maximum. Check $g(3)=1$ and $g(4)=-1$.

## Smaller skills within this topic

Practise each skill separately, then combine them in problems:

1. Track horizontal versus vertical changes to a base graph.
2. Describe reflections and stretches with accurate factors.
3. Find the new domain, range, intercepts and a transformed landmark.

## Why the method works

Changing $f(x)$ outside the function changes its output directly. Changing the input to $f(bx+c)$ affects horizontal coordinates in the opposite apparent direction because the old input must be reconstructed. The safest approach is to transform a distinctive point: if $(u,v)$ is on $y=f(x)$, solve $bx+c=u$ for its new $x$-coordinate.

## A contrasting worked route

From $f(x)=x^2$, $g(x)=2f(x-3)+1=2(x-3)^2+1$ has vertex $(3,1)$, vertical stretch factor $2$ and range $[1,\infty)$. Substituting $x=3$ checks the new vertex. If the input were $f(2x)$, the old point at $x=4$ would move to $x=2$, a horizontal compression.

## Transfer and validation

List transformations in an order compatible with the expression; noncommuting shifts and stretches can produce different graphs. For a restricted original domain, apply the same input equation to map its endpoints. A graphing tool can verify a proposed transformation, but describe the coordinate map to justify it.

## Exam lens

Paper 1 style: describe the transformation sequence and track an anchor point, such as the vertex. This is a practice lens, not a prediction of an examination question.

## A mistake worth catching

$f(x+3)$ shifts left $3$, not right $3$. Solve $x+3=0$ to see where the old anchor at $0$ goes.

## Try it yourself

Where does the vertex of $y=x^2$ move under $y=(x+4)^2-2$?

## Checked answer

To $(-4,-2)$.
