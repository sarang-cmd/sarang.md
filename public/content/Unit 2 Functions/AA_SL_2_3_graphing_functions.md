# Graphing functions

> **SL 2.3 · AA SL foundation (also studied at HL)** · Original Sarang.md course lesson, not an IB publication.

## Understand the idea

A graph is a visual set of input-output pairs. Intercepts, vertex positions, symmetry and end behavior reveal structure before any plotting tool is used. A table samples the function but cannot prove there are no other features.

## Formula, meaning and conditions

For $y=ax^2+bx+c$, the axis of symmetry is $x=-b/(2a)$ when $a\neq0$. To find $x$-intercepts set $y=0$; to find a $y$-intercept set $x=0$. Label axes and choose a window that shows relevant behavior.

## Worked example

Sketch $f(x)=x^2-4$. Since the square is nonnegative, the minimum is $-4$ at $x=0$, giving vertex $(0,-4)$. Setting $x^2-4=0$ yields intercepts $(-2,0)$ and $(2,0)$; the $y$-intercept is $(0,-4)$. The graph opens upward and is symmetric about the $y$-axis.

## Smaller skills within this topic

Practise each skill separately, then combine them in problems:

1. Create a useful value table and plot correct coordinates.
2. Locate intercepts and asymptotes before drawing a smooth curve.
3. Check end behavior, symmetry and scale rather than joining arbitrary dots.

## Why the method works

A graph condenses input-output structure, not just a set of sampled points. Intercepts arise from setting one coordinate to zero when that input exists. An asymptote describes behavior near an excluded input or far from the origin; it is not automatically a barrier that can never be crossed. Technology produces pixels, while reasoning supplies domains and scale choices.

## A contrasting worked route

For $y=1/(x-2)+1$, $x=2$ is excluded and $y=1$ is not attained, giving asymptotes $x=2$ and $y=1$. At $x=0$ the intercept is $(0,1/2)$, while $y=0$ gives $x=1$. A sketch passing through $(2,1)$ would be false even if nearby sampled values seem smooth.

## Transfer and validation

State the viewing window when describing a graph obtained with technology. A narrow window can hide distant roots; a wide one can flatten local features. Verify visually suggested solutions by substituting into the original equation and explaining any points where the formula is undefined.

## Exam lens

Paper 1 style: mark exact intercepts and a turning point rather than drawing an unlabeled curve. This is a practice lens, not a prediction of an examination question.

## A mistake worth catching

A graphing window may hide an intercept or turning point. A blank screen is not evidence that the function has no values.

## Try it yourself

List the intercepts and vertex of $y=(x-1)^2-9$.

## Checked answer

Vertex $(1,-9)$, $x$-intercepts $(-2,0)$ and $(4,0)$, and $y$-intercept $(0,-8)$.
