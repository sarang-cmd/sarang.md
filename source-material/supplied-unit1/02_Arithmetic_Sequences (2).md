# Arithmetic Sequences

One of the first things taught in this unit — a classic "easy mark" area, and exactly the kind of basic that's easy to get rusty on since it was taught weeks ago.

## Definition

An arithmetic sequence adds a fixed **common difference \(d\)** to each term: \(u_{n+1}=u_n+d\).
- \(d = u_{n+1}-u_n\), constant for every consecutive pair — this is how you test if a sequence is arithmetic.
- \(d\) can be positive, negative, or zero.

## Key Formula

$$u_n = u_1 + (n-1)d$$

In the formula booklet — you must be able to rearrange it for any unknown.

## Worked Examples

**1. Find a term.** \(u_1=7\), \(d=3\). Find \(u_{20}\): \(7+19(3)=64\).

**2. Find \(d\) and \(u_1\) from two terms.** \(u_4=20\), \(u_9=45\): \(u_1+3d=20\), \(u_1+8d=45\) → \(5d=25 \Rightarrow d=5\), \(u_1=5\).

**3. Find \(n\).** Which term equals 100 in the AP above? \(5+(n-1)5=100 \Rightarrow n=20\).

**4. Test if arithmetic.** Is \(3,7,11,16\) arithmetic? Differences \(4,4,5\) — not constant, **no**.

## Question Types

- Find nth term / first term / common difference given two terms — simultaneous linear equations.
- "Is this sequence arithmetic? Justify." — check at least three consecutive differences.
- "Which term equals X?" — solve for \(n\); it must be a positive integer or X isn't actually a term.
- Algebraic consecutive terms (e.g. \(x-2, x+1, 2x+3\)) — set consecutive differences equal.

## Common Mistakes

- Using \(n\) instead of \((n-1)\) — the single most common error.
- Forgetting \(d\) can be negative.
- Checking only one pair of terms when testing "is it arithmetic."
- Getting a non-integer \(n\) and not going back to check your algebra.

## Self-Test

1. Find the 15th term of \(u_1=-4\), \(d=6\).
2. \(u_5=18\), \(u_{12}=53\). Find \(u_1\) and \(d\).
3. Is \(2,5,9,14\) arithmetic? Justify.
4. Three consecutive AP terms: \(x-1, 2x+1, 4x-3\). Find \(x\).

**Answers:** 1. \(80\). 2. \(d=5, u_1=-2\). 3. Differences \(3,4,5\) — not constant, not arithmetic. 4. \(x=6\).
