# Sarang.md: requests compared with the implementation

**Audit date:** 26 September 2026. This compares the requirements recorded in our conversation with the current workspace, source files and checks. It distinguishes a feature being coded from a feature being deployed or proven against live third-party services. It does not certify IB material, mathematical correctness of every worked answer, sound quality, or production security.

**Status key:** **Verified locally** means inspected or exercised in this workspace. **Implemented, live check pending** means the interface and code exist, but an external service or real deployment has not been tested. **Partial** means the requested direction exists but does not yet have the full depth or assurance originally sought. **Owner action** means an account, document, decision or deployment controlled by you is still needed.

## Checks performed, and what they do not prove

- `npm run check:data`, `npm run test:profile`, `npm run test:sounds` and `npm run build` passed after this expansion. Data checks cover 83 lessons, five guides, unchanged source notes, 1,003 original question IDs, linked syllabus coverage, 9,341 rendered math fragments and 106 independent numerical spot checks across 34 practice families. They do not certify every answer.
- A prior source-only rebuild without `uploads/` reproduced a supplied note byte-for-byte. The older ZIP lacked ignored source inputs and could **not** rebuild. That reproducibility issue was fixed by versioning the 22 notes and outline under `source-material/`. The current archive `Sarang-md-AAHL-Booklet-1003-2026-09-26.zip` was clean-extracted without `uploads/` and passed `npm ci`, data/profile/sound checks and the production build. A supplied note and the regenerated question bank matched byte-for-byte. Do not merge it into the old `ver.5` folder.
- Earlier browser checks exercised movable panels, a practice/profile flow, offline tutor hints and deliberate reveal, mock video commands, Auth request shapes, tooltips and nonzero Web Audio output. The current production build passed a Chromium smoke check for five strands, expanded lesson math and answer reveal, booklet guide, 80-result batching, deep links to new skills, seeded P1/P2/P3 mock totals, preserved banks and mobile page width. An earlier check also verified an out-of-window deep link stayed visible. External provider and cloud return paths were not tested. Browser tests are ad hoc, not a checked-in CI suite.
- The most recent Vite build succeeded with a **non-fatal warning** about JavaScript chunks larger than 500 kB. A large PDF worker is also bundled. This is a performance consideration, not a failed build.

## Boundaries and known issues that should not be hidden

1. **Cloud security is not verified in production.** The migration is written but has not been installed from here. Until the owner tests RLS, direct-write denial, revision conflicts and two-user isolation on the real Supabase project, cloud backup should be treated as unverified.
2. **Full independent editorial sign-off is still missing.** The supplied 2023 Version 1.0 HL booklet has been mapped for its listed rows and caveats in `FORMULA_BOOKLET_AUDIT.md`, but a row mapping cannot certify every worked answer. Original marking guides are educational suggestions, not official IB schemes. Preserved source transcriptions include metadata conflicts and preserved notes include known numeric errata.
3. **Course completeness has a documented boundary.** The 83 lessons have approximately 400 to 500 prose words and mapped smaller skills per supplied outline heading, but no one set of headings proves coverage of every detail of a complete official subject guide. Further elaboration and an independent worked-answer audit remain worthwhile.
4. **Publishing and privacy remain owner decisions.** The public build contains bundled notes and original practice, while browser-imported local notes are unencrypted IndexedDB data. An encrypted vault, a Supabase account session and saved browser preferences have different storage and deletion behavior. Review supplied text and its distribution rights before public deployment.
5. **Playback and AI rely on external providers.** YouTube embeds, unmuted autoplay, CORS, rate limits, model behavior and third-party privacy policies cannot be guaranteed by this static app.
6. **The repository is not updated remotely.** The last push attempt failed for lack of authentication. In this workspace snapshot `git remote -v` may be empty because local Git configuration is not part of the saved snapshot; the owner must inspect or restore the remote before pushing. Never use a force push to conceal divergence.
